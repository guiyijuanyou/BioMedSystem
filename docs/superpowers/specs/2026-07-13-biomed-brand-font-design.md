# BioMed Cloud 品牌字体设计

## 目标

增强顶栏左上角 `BioMed Cloud` 的品牌识别度，同时保持医疗科研后台所需的专业性和信息密度。

## 已确认方案

- 品牌英文字体使用 Google Fonts 的 `Fraunces`。
- 品牌英文字重使用 `900`，形成明确的黑体视觉效果。
- 桌面顶栏品牌字号使用 `18px`。
- 品牌字间距保持 `0`。
- 使用 Fraunces 的可变字体设置保留适度的柔和曲线和特色字形。
- 中文副标题继续使用当前系统无衬线字体，不随英文品牌名切换为 Fraunces。

## 应用范围

统一应用到已登录桌面顶栏和登录页顶栏中的 `BioMed Cloud` 品牌名。其他页面标题、导航项目和正文不使用 Fraunces。

## 字体加载

通过项目依赖引入 Fraunces 字体资源，避免仅依赖用户设备字体。加载范围应覆盖 `900` 字重，并保留现有字体作为回退。

## 响应式行为

品牌区域保持单行显示和现有截断逻辑。窄屏下不得挤压导航操作或造成品牌名与副标题重叠。

## 验收标准

- `BioMed Cloud` 在桌面顶栏中以 Fraunces 900、18px 显示。
- 中文副标题的字体和可读性不受影响。
- 登录页与已登录页面的品牌字体一致。
- 字体加载失败时仍有可读的衬线字体回退。
- 前端构建和现有测试通过。
