# 登录弹窗 Stepper 改版设计

## 目标

将现有登录弹窗改造成三步式登录流程，布局和交互参考用户提供的 Vue Bits Stepper 示例，同时沿用项目现有的生物医药数据门户视觉体系。改动严格限制在前端，现有登录接口、认证数据结构、登录成功跳转和错误来源保持不变。

## 范围

- 新增可复用的 Vue Stepper 组件。
- 将登录表单拆分为“账号”“密码”“确认登录”三个步骤。
- 调整登录弹窗样式、动画和响应式布局。
- 更新登录相关前端测试和依赖。
- 不修改 `backend/`、`/api/auth/login`、用户数据或权限逻辑。
- 不改变登录页其余五段叙事页面、导航和三维背景。

## 组件结构

### Stepper 组件

在登录组件目录下新增独立的 `Stepper.vue`，封装以下职责：

- 管理当前步骤、前进和后退方向。
- 渲染三个圆形步骤节点及连接线。
- 完成步骤显示勾选，当前步骤显示实心圆点，未完成步骤显示序号。
- 使用 `motion-v` 实现内容切换、节点状态、连接线填充和容器高度动画。
- 通过插槽承载各步骤内容。
- 对外提供步骤变化和最终完成事件。
- 默认禁止直接点击未完成的步骤节点，避免绕过必填字段。

### LoginModal 组件

保留现有弹窗、关闭按钮、密码可见性切换、演示账号和提交事件，并将表单内容组合到 Stepper 中：

1. 账号步骤：账号输入框，非空后允许进入下一步。
2. 密码步骤：密码输入框、显示/隐藏密码按钮和演示账号入口，非空后允许进入下一步。
3. 确认步骤：显示当前账号摘要、返回修改入口、接口错误信息和最终登录按钮。

最终按钮继续触发当前的 `submit` 事件，提交 `{ username, password }`。`LoginView.vue` 中现有 `/api/auth/login` 请求及成功后的路由跳转不改变。

## 交互规则

- 打开弹窗时从第一步开始，并聚焦账号输入框。
- 账号或密码为空时不进入下一步，在当前步骤显示简短校验提示。
- 按 Enter：前两步进入下一步，第三步提交登录。
- “上一步”返回前一项并保留已输入内容。
- 登录失败停留在第三步，展示现有接口错误文本。
- 登录加载期间禁止重复提交、后退和关闭弹窗。
- 关闭后再次打开时重置到第一步，但继续使用父组件传入的默认账号和密码。
- 演示账号仍使用统一密码 `123456`，点击账号可直接填入账号，不触发后端请求。

## 视觉系统

- 保留当前浅色半透明弹窗、深蓝主文字和柔和遮罩。
- 主强调色采用现有页面的紫色、粉色和橙色渐变，不引入绿色参考图配色。
- 步骤节点和完成连接线使用紫色到橙色的渐变；未完成状态使用低对比灰紫边框。
- 面板尺寸接近参考图的紧凑居中卡片，保持现有圆角、阴影和右上角关闭按钮。
- 输入框沿用现有浅灰背景和紫色聚焦描边。
- “下一步”和最终“登录系统”使用同一渐变按钮体系。
- 最终登录按钮保留现有光栅掠过动画，并支持 `prefers-reduced-motion`。
- 桌面端保持居中弹窗；窄屏降低内边距、按钮稳定换行且不产生横向溢出。

## 状态与数据流

`LoginView.vue` 继续拥有登录请求、加载状态和接口错误状态。`LoginModal.vue` 只管理本地输入值、当前步骤、密码显隐和演示账号展开状态。Stepper 只管理步骤导航，不感知认证接口。

数据流如下：父组件凭据 -> 登录弹窗本地副本 -> Stepper 分步编辑 -> 最终 `submit` 事件 -> 原有登录请求 -> 成功关闭并跳转或失败显示错误。

## 错误处理

- 本地空值校验不调用后端。
- 后端错误继续使用 `error.message`，不改写响应格式。
- 如果用户返回前两步修改凭据，旧接口错误提示会在再次提交前清除或隐藏，避免误导。
- 动画组件不可用或用户开启减少动态效果时，内容仍可正常切换和提交。

## 测试与验收

- 单元测试覆盖三个步骤的前进、后退、必填校验和最终提交数据。
- 单元测试覆盖演示账号、密码显隐及关闭重开后的步骤重置。
- 运行现有 Vitest 测试和 Vite 构建，确认没有影响登录页其他模块。
- 按用户要求，不由 Codex 执行最终视觉验收；用户在浏览器中检查实际配色、间距和动画观感。

## 文件影响

- `frontend/package.json` 和锁文件：增加 `motion-v`。
- `frontend/src/components/login/Stepper.vue`：新增通用步进组件。
- `frontend/src/components/login/LoginModal.vue`：改造成三步登录流程。
- `frontend/src/styles/login-experience.css`：增加或调整 Stepper 和登录弹窗样式。
- `frontend/src/components/login/__tests__/loginExperience.test.js`：更新登录流程测试。
