# 登录后药用叶片数据背景设计

## 目标

为认证后的管理后台增加一套安静、可持续运行的全局 3D 背景。视觉主体是一片具有数据叶脉的药用植物叶片，用生命结构表达中药材资源、样本采集、质量研究和溯源数据之间的关系。

本设计只作用于登录成功后的应用壳层。登录前的沉浸式首页、`LoginView.vue`、`BiomedScene.vue`、`DnaHelix.vue`、滚动叙事和登录页样式全部保持不变。

## 技术栈约束

实现必须沿用沉浸式首页现有技术栈：

- Vue 3 Composition API
- Vite
- Three.js
- TresJS
- GSAP ScrollTrigger
- Lenis
- Lucide Vue
- Vitest
- Vue Test Utils
- CSS/SVG

不得新增 OGL、Vue Bits 运行库、第二套 3D 引擎、模型加载器、动画库或其他前端依赖。背景不强制使用技术栈中的每一个库；GSAP ScrollTrigger 与 Lenis 继续承担项目现有的滚动和动效基础设施，背景不得创建第二套滚动控制器。Lucide Vue 不参与纯装饰背景渲染。

## 视觉方向

背景主体为一片偏右放置、略微弯曲的半透明药用植物叶片：

- 叶片使用通用的披针形药用植物轮廓，不指代某一种具体药材。
- 主叶脉从叶柄延伸到叶尖，次级叶脉向两侧展开。
- 少量发光数据点沿主叶脉和次级叶脉缓慢流动。
- 叶片周围保留低密度环境粒子，暗示样本和数据节点。
- 颜色与沉浸式登录页保持同一视觉语言，只使用白色、蓝色、紫色、橙色及其渐变。
- 叶面通过 Three.js 顶点色形成由蓝色向紫色过渡的柔和渐变，叶缘和流动数据点使用少量橙色强调。
- 叶片不能形成高饱和实体色块，也不能压过表格、地图、表单和操作按钮。

背景采用固定全屏构图，不随业务页面高度扩展。叶片主要出现在页面右侧和中后景，左侧标题、导航及高密度内容区域保留更稳定的负空间。

## 组件架构

### `AuthenticatedLeafBackground.vue`

认证后背景入口，挂载在 `App.vue` 已登录分支的 `.shell` 内。

职责：

- 提供 CSS/SVG 静态基础层。
- 根据媒体查询、页面可见性和 WebGL 能力决定是否挂载 3D 场景。
- 异步加载 `MedicinalLeafScene.vue`，避免登录前加载认证背景代码。
- 将背景标记为装饰性内容并禁止指针事件。
- WebGL 初始化或异步加载失败时保留静态背景，不影响业务页面。

### `MedicinalLeafScene.vue`

单一 TresJS Canvas，负责相机、灯光和药用叶片场景。

职责：

- 使用与 `BiomedScene.vue` 一致的 `TresCanvas`、透视相机和基础灯光模式。
- 使用 `useLoop` 驱动极慢的叶片呼吸、旋转和数据点流动。
- 页面隐藏或动画被禁用时停止状态更新。
- 只读取展示配置，不访问路由业务数据或接口。

### `MedicinalLeafModel.vue`

程序化生成叶片、叶脉、数据点和环境粒子。

职责：

- 使用 Three.js `BufferGeometry` 构造弯曲叶面。
- 使用 `LineSegments` 或等价单批次几何绘制主叶脉与次级叶脉。
- 使用 `InstancedMesh` 绘制流动数据点，禁止为每个点创建独立 Mesh。
- 使用单个 `Points` 对象绘制低密度环境粒子。
- 统一释放几何体、材质和 WebGL 资源。

### `useAuthenticatedBackground.js`

管理背景运行条件和稳定配置：

- `prefers-reduced-motion`
- 移动端或粗指针设备
- `document.visibilityState`
- WebGL 支持状态
- DPR、粒子数量和动画强度

该 composable 不处理登录页状态，也不创建 Lenis 或 ScrollTrigger 实例。

## 几何与绘制预算

背景应控制在约 4 至 6 次绘制调用：

1. 一次叶面 Mesh。
2. 一次叶脉 LineSegments。
3. 一次实例化数据点。
4. 一次环境 Points。
5. 必要时增加一次叶柄或柔光层。

叶片使用低到中等分段的自定义 BufferGeometry，不加载 GLB、GLTF、HDR、纹理贴图或远程模型资源。视觉细节主要由顶点形变、材质透明度、灯光和线条完成。

## 动效

- 叶片只做低频呼吸、轻微摆动和缓慢旋转。
- 数据点沿预定义叶脉路径连续流动，但数量保持低位。
- 不提供鼠标追踪、点击反馈或大幅视差。
- 路由切换不重建 Canvas，不改变模型类型，只允许背景透明度做短暂柔和过渡。
- 背景不直接绑定页面滚动，不与 Lenis 或 ScrollTrigger 竞争动画帧。
- 页面隐藏时暂停 `useLoop` 中的状态更新。

## 布局集成

- `.shell` 建立认证背景所需的独立层叠上下文。
- 背景层使用 `position: fixed; inset: 0; pointer-events: none`。
- 背景位于顶部导航、工作区、浮动助手、抽屉遮罩和 Toast 之后。
- 现有业务布局、导航结构、表格、地图和表单不发生位移。
- 现有白色或半透明表面继续承担内容可读性，不增加大面积嵌套玻璃卡片。
- CSS/SVG 静态层始终存在，Canvas 只是渐进增强。

## 配色

- 基础背景：白色 `#ffffff`、浅蓝灰 `#f6f9fc`、`#edf4ff`
- 蓝色：`#0073e6`、`#68cfff`
- 紫色：`#635bff`、`#7a5cff`
- 橙色：`#ff7a59`、`#ff8a4c`
- 叶面渐变：从蓝色过渡到紫色，局部边缘混入低比例橙色
- 叶脉：以白色柔光和蓝色为主，紫色用于层级变化
- 数据点：蓝色、紫色为主，橙色只作为少量高亮节点
- 文字与业务内容继续使用当前认证主题变量，不由背景组件修改

CSS 静态层使用与沉浸式登录页一致的白色基底和蓝、紫、橙径向渐变，但降低饱和度与透明度。叶面整体透明度保持低位，模型与内容交叠处通过 CSS 遮罩和材质透明度退到内容后方，不通过模糊滤镜制造层级。不得引入绿色、粉色或与该调色板无关的主色。

## 性能与降级

- 认证背景通过 Vue 异步组件加载，登录前不下载或初始化该场景。
- 桌面端 DPR 控制在 `1` 至 `1.25`。
- 移动端、粗指针设备和 `prefers-reduced-motion: reduce` 默认只显示 CSS/SVG 静态背景。
- 浏览器标签页隐藏时停止动画状态更新。
- 全部认证页面共用一个 Canvas，路由切换不重复创建 WebGL 上下文。
- 不使用实时阴影、后处理、环境贴图、物理传输材质或高成本模糊。
- WebGL 不可用、上下文丢失或异步场景加载失败时，业务页面继续正常显示静态背景。
- 背景不得降低地图拖拽、页面滚动、表格操作和表单输入的响应速度。

## 可访问性

- 背景容器设置 `aria-hidden="true"`，不进入可访问性树。
- 背景不接收焦点和指针事件。
- 高对比度、减少动态效果和移动端环境优先使用静态降级层。
- 背景不能改变现有焦点样式、错误提示、地图标记和操作控件的对比度。

## 测试与验证

### Vitest 与 Vue Test Utils

- 未认证的登录页不导入或渲染 `AuthenticatedLeafBackground`。
- 认证后的 `.shell` 只挂载一个背景入口。
- 移动端、减少动态效果、页面隐藏和 WebGL 不可用时返回正确降级状态。
- DPR、粒子数量和动画强度保持在约束范围内。
- 背景容器为装饰性、不可交互层。
- 现有登录体验测试继续通过，证明登录前页面未被修改。

### 构建与运行验证

- 全量前端测试通过。
- Vite 生产构建通过。
- 登录流程可进入认证页面，控制台无背景相关错误。
- Canvas 非空且固定覆盖视口，不增加页面宽高或拦截交互。
- 桌面与移动视口均无内容遮挡；移动端确认使用静态降级层。
- 视觉风格最终由用户验收，自动化只验证非空渲染、布局边界、交互可用性和运行稳定性。

## 明确不包含

- 不修改沉浸式登录首页及其 DNA 场景。
- 不替换或复用 `DnaHelix.vue`。
- 不引入新技术、新依赖或远程 3D 资源。
- 不重做认证后的导航、业务卡片、表格、地图或表单布局。
- 不为不同业务路由创建不同 3D 模型。
- 不增加与业务功能无关的文字、控件或说明卡片。
