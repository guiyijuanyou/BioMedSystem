# 登录后桌面端顶部导航改造设计

## 目标

将登录后全部页面的左侧导航改为桌面端顶部导航。布局关系参考 Benchling：一级模块横向排列，二级目录通过鼠标悬停展开；具体组件外观继承项目沉浸式首页，不复制 Benchling 的组件样式。

本次是纯展示层改造。现有路由、权限、接口调用、状态管理、表单提交、刷新、备份、用户菜单和退出登录逻辑必须保持不变。

## 范围

- 覆盖登录后的全部页面。
- 本轮只处理桌面端布局。
- 现有移动端逻辑和布局不主动改造。
- 不修改后端、API 服务、权限矩阵或业务页面脚本。
- 保留用户在 `frontend/src/composables/useImmersiveScroll.js` 中尚未提交的修改，不触碰该文件。

## 信息架构

顶部一级导航继续使用现有角色菜单与权限计算结果：

- 工作台
- 药材资源
- 质量科研
- 教学培训
- 评价改进
- 成果管理
- 系统管理

工作台为直接入口。其余一级导航按现有 `groupDefinitions` 展示二级目录。菜单项继续使用当前路由映射：工作台、资料文件、专业改进闭环和各业务模块的跳转地址不变。

## 页面结构

登录后的桌面页面采用两层顶部结构：

1. 顶部主导航负责品牌、一级模块、悬浮二级菜单和用户入口。
2. 页面工具栏负责当前页面标题、角色、自动备份、刷新等页面级操作。

移除桌面端侧边栏占位后，内容区使用完整可用宽度。内容容器设置稳定的最大宽度、左右边距和纵向间距，不改变业务页面内部的数据结构和交互结构。

## 视觉系统

组件样式以沉浸式首页为唯一视觉基准：

- 页面背景使用首页的浅色 `#f6f9fc` 系列。
- 主文字使用 `#0a2540`，弱化文字使用 `#53657d` 或 `#697386`。
- 主交互色使用 `#635bff`，蓝、青和珊瑚色仅用于状态区分和轻量点缀。
- 顶部导航使用半透明白色表面、细边框、柔和阴影和背景模糊。
- 导航、下拉面板、工具栏、内容面板、指标、表单和表格统一使用圆角组件语言。
- 桌面后台页面保持紧凑、可扫描的信息密度，不引入营销页式大标题或装饰性卡片堆叠。
- 图标继续使用项目已有的 `lucide-vue-next`。

## 悬浮下拉行为

- 鼠标进入带二级目录的一级入口时展开菜单。
- 下拉层使用独立绝对定位，悬浮覆盖页面内容，不参与文档流。
- 菜单打开或关闭时，页面工具栏、工作台和业务内容的坐标与尺寸不得改变。
- 鼠标可从一级入口连续移动到下拉面板；离开入口与面板后延迟约 160 毫秒关闭。
- 当前一级模块使用首页风格的渐变下划线或轻量色彩提示。
- 下拉菜单使用圆角、半透明白色、细边框、背景模糊和柔和阴影。
- 简单悬停反馈使用 CSS transition；菜单进入与退出使用项目已有 GSAP，仅改变透明度和轻微纵向位移。
- 遵守 `prefers-reduced-motion`，不增加新的动画依赖。

## 代码边界

主要改动限定在：

- `frontend/src/App.vue`
- `frontend/src/components/SidebarNav.vue`
- `frontend/src/styles.css`
- 与顶部导航展示逻辑直接对应的前端测试文件

`SidebarNav.vue` 保留现有文件名，以缩小引用和改动范围。组件内部可调整为顶部导航的模板结构，但以下内容保持原有语义：

- `items` 与 `roleLabel` 输入
- `groupDefinitions` 分组
- `activeKey` 和 `activeGroup` 计算
- 路由目标
- 权限过滤结果
- 导航后关闭移动菜单的事件

`App.vue` 只调整登录后壳层模板的展示顺序和 CSS 类，不改变现有函数、接口调用、provide 数据、路由参数、事件处理和状态更新。

## 逻辑验收

按照用户要求，不进行最终视觉对稿、像素级验收或设计成品打分。只验证展示层改造没有改变或破坏既有逻辑：

- 未登录用户仍进入登录页。
- 登录后仍按原重定向进入目标页面。
- 各角色只看到 `roleMenus` 允许的模块和二级入口。
- 工作台、资料文件、专业改进闭环、批次档案及各模块路由仍可正常访问。
- 导航激活状态与当前路由一致。
- 刷新、自动备份、个人中心、修改密码和退出登录行为保持正常。
- 二级菜单项点击后仍调用原路由映射。
- 现有业务页面的 API、表单和数据处理脚本没有改动。
- 现有测试、新增导航测试和生产构建通过。

## 非目标

- 不重构移动端导航。
- 不修改业务数据结构或页面功能。
- 不重写权限系统。
- 不修改沉浸式首页或登录流程。
- 不复制 Benchling 的品牌、文案、色板或具体组件造型。
- 不新增前端框架、动画库或状态管理库。
